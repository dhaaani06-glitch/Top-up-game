# TopUpKu — HTML Vercel

Template toko top-up game sederhana, tanpa backend/database.

## Upload ke Vercel
1. Upload folder/proyek ini ke GitHub atau import folder ZIP ke Vercel.
2. Framework preset: **Other** / static.
3. Tidak perlu build command.
4. Setelah deploy, buka `index.html`.

## Fitur
- List game & nominal
- Pencarian game
- Form User ID & Zone ID
- Nama & WhatsApp
- Upload bukti transfer
- Nomor pesanan otomatis
- Cek status pesanan
- Dashboard admin
- Verifikasi / tolak manual
- Responsive untuk iPhone

## Penting
Versi ini adalah **demo frontend**. Data memakai `localStorage`, sehingga data customer dan admin tidak tersinkron antar perangkat/browser.

Untuk toko sungguhan, tambahkan backend + database + penyimpanan gambar + autentikasi admin.
